Memory Engine & Storage

5-Tier Memory Pyramid & Databases

Cross-task learning and architectural recall powered by hybrid relational and semantic vector storage.
Persistent Memory Hierarchy
Tier 1: Ephemeral Context Token Window & Top-K RAG
Tier 2: Real-Time State Redis 7 Pub/Sub & Pipeline Locks
Tier 3: Relational Audit PostgreSQL 15 ACID (Cloud SQL)
Tier 4: Long-Term Semantic pgvector (1024-dim Cosine Similarity)
Tier 5: Workspace Artifacts Local Workspaces & Google Cloud Storage
• PostgreSQL 15 + pgvector
Stores 1024-dimension embeddings via llama-nemotron-embed-vl-1b. Uses cosine distance (<=>) for instant recall of security policies, PR reviews, and architectural decisions.
• Redis 7 Pub/Sub & Streams
Synchronizes multi-agent conversation state across tasks and streams live WebSocket logs to the React frontend dashboard in real time.
• Custom Model Context Protocol (MCP)
Tool boundary stdio servers: logger_mcp, security_mcp, quality_mcp, and pipeline_status_mcp safely insulate the host OS.
